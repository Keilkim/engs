# 2026-11-11 · 문법 밑줄: 고정은 실선, 자리는 물결

- 기존 공개 저장소 `Keilkim/engs`의 `main`에 반영하고, Vercel 자동 배포(<https://engs-red.vercel.app>)로 내보낸다.
- 저장된 표현의 고정 단어는 진한 파랑 1.2px 실선, 바뀔 수 있는 자리를 채운 단어는 옅은 파랑 물결로 표시한다. 색뿐 아니라 선 모양으로도 구분되어, 화면이 어둡거나 색 구분이 어려워도 알아볼 수 있다. 자리 표기(A, ~, v …)는 물결 아래에 그대로 둔다. 같은 날 앞선 릴리스의 파선 표기를 대체한다.
- 페이지의 물결과 자리 표기는 페이지 비율대로 늘어나는 SVG 대신 HTML 층에 그려 모양이 찌그러지지 않는다. 기울어진 스캔에서는 물결도 줄 기울기를 따르며, 각도는 측정한 페이지 크기로 계산한다(Safari 18 이전은 CSS `atan2()`의 서로 다른 단위를 잘못 계산하므로 CSS에 맡기지 않는다). 문법 팝업의 문장 조각도 같은 실선·물결을 쓰고, 여러 줄로 넘어가는 긴 조각은 줄마다 표시한다.
- 데이터·스키마·API 변경은 없고 CSS와 표시 컴포넌트만 바뀐다. 직전 배포로 복구 가능하다.
