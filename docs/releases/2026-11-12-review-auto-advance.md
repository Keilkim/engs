# 2026-11-12 · 복습: 정답은 자동으로 넘기고, 저장은 뒤에서

- 기존 공개 저장소 `Keilkim/engs`의 `main`에 반영하고, Vercel 자동 배포(<https://engs-red.vercel.app>)로 내보낸다.
- 복습 피드백 화면에서 손 모양 안내(손 이미지·탭 광선)를 뺐다. `확인하고 터치!` 문구는 남긴다.
- 정답이면(뜻 고르기, `맞혔어요` 자기 체크, 말하기 확인 모두) `맞았어요!`를 1.1초 보여주고 다음 카드로 자동으로 넘어간다. 그 전에 화면을 눌러 바로 넘어가도 된다. 틀렸거나 `기억 안 나요`·`잘 모르겠어요`일 때만 터치해야 넘어가고, `확인하고 터치!`도 이때만 보인다. 탭이 가려져 있으면 넘어가지 않고, 돌아와 이어서 하면 다시 1.1초를 센다.
- 오늘의 복습 결과는 답하는 즉시 다음 카드로 넘어간 뒤 백그라운드에서 서버에 저장한다. 저장을 기다리던 `다음 카드 준비 중`·`기억을 담고 있어요`와 먼지 구름 표시는 없앴다.
- 저장이 끝나지 않은 답은 이어하기 기록에 `pending`으로 남는다. 실패하면 화면을 막지 않고 `복습 결과 n개를 아직 저장하지 못했어요 · 다시 저장`을 보여 준다. 저장 중 페이지를 닫았다면 다음에 열 때 다시 저장한다. 다음 묶음을 불러오거나 다른 연습을 시작하기 전에도 남은 저장을 먼저 보낸다. 그래서 방금 답한 카드가 아직 예정 항목으로 다시 뽑히지 않는다. 서버 저장은 이미 같은 날 기록된 항목을 다시 진행시키지 않으므로(`alreadyRecorded`) 재시도해도 SM-2 간격이 두 번 진행되지 않는다.
- 스키마·API·인증 변경은 없다. 이어하기 기록에 선택 필드 `pending`이 붙을 뿐이라, 직전 배포로 코드 복구가 가능하다.
