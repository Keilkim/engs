# 단어 학습을 피하거나 중단하는 이유: 조사 근거

조사일: 2026-10-30 · 대상 제품: 오렌지 더스트

## 조사 범위와 읽는 법

단어 복습의 시작·지속·중단·복귀에 영향을 주는 실패를 찾았다. 학술 원문, 서비스 공식 문서와 실험 보고, 공개 사용자 후기를 함께 검토했다. 검색은 언어 학습 앱 중단, 복습 누적, 게임화 부작용, 모바일 사용 맥락, 음성 인식 불만, 인출 연습과 간격 효과를 중심으로 진행했다. 관련 없는 기술 일반론과 근거가 불명확한 이탈률 수치는 채택하지 않았다.

이 문서는 체계적 문헌고찰이나 시장 전체의 불만 빈도 조사에 해당하지 않는다. 실패 관련 검색에는 부정적 사례가 더 잘 걸리므로 긍정적 결과와 반례도 함께 기록했다. 외국어·국가·연령이 다른 결과를 한국 성인 영어 학습자 전체에 그대로 적용할 수 없다.

- **연구:** 조건과 표본 안에서 관찰한 결과. 실험, 설문, 인터뷰의 증거 성격을 구분한다.
- **공식 자료:** 실제 제품의 동작이나 업체가 보고한 실험. 외부 검증 여부와 측정한 결과의 범위를 확인한다.
- **후기:** 실제 작성자의 경험 진술. 독립적으로 검증된 성능이나 전체 사용자의 비율로 해석하지 않는다.
- **설계 추론:** 위 근거에서 도출한 우리 제품의 가설. 실제 고객 조사로 확인해야 한다.

기존 [페르소나 5명](../../personas/README.md)은 가상 인물이며 아래 근거의 참여자들이 아니다.

## E01 · 앱이 싫어서 떠나는 경우와 학습 자체를 쉬는 경우

**자료:** Huang (2024), 앱 사용 경험자 186명 설문. [논문과 초록](https://www.castledown.com/journals/tltl/article/view/tltl.v6n2.1187)

**관찰:** 사용 시작·감소·재개를 조사했다. 중단에는 앱 불만 같은 제품 요인과 언어 학습 중단 같은 사용자 측 요인이 함께 있었으며, 언어 학습을 재개하는 것이 앱 재사용의 주요 계기로 나타났다.

**해석의 한계:** 회고적 설문이며 특정 기능의 인과 효과를 측정한 실험이 아니다. ‘앱을 안 켬’을 곧바로 UX 실패로 분류해서는 안 된다.

**우리 가설:** 휴식·목표 달성·다른 학습 수단으로 이동·제품 불만을 구분해 묻는다. 복귀 시 과거 진도와 현재 목표를 연결하는 기능을 검토한다.

## E02 · 의욕적으로 많이 추가했다가 복습량에 압도됨

**자료:** Anki 공식 매뉴얼, Daily Limits와 New Cards Ignore Review Limit. [Deck Options](https://docs.ankiweb.net/manual/deck-options)

**관찰:** 새 카드를 많이 공부하면 뒤이어 복습 부담이 늘어난다고 설명하며, 초기에 많은 카드를 학습한 뒤 부담을 느끼는 사용 사례를 명시한다. 복습이 밀린 상황에서 신규 학습을 계속 추가하면 누적을 악화시킬 수 있다고 안내한다.

**해석의 한계:** 공식 사용 지침이지, 전체 사용자의 이탈률이나 특정 일일 분량의 효과를 입증하는 실험이 아니다. 매뉴얼의 예시 수치를 우리 앱의 예측치로 사용하지 않는다.

**우리 가설:** 참고용 저장과 실제 복습 편입의 관계를 검토한다. 작은 세션으로 나눠 보여주는 것만으로 누적 문제가 해결되지는 않으므로 신규 편입량과 반복 부담도 함께 다뤄야 한다.

## E03 · 쉬고 돌아오니 800개가 기다려 시작하지 못함

**자료:** Reddit r/Anki 공개 후기. [몇 달 쉬고 돌아온 뒤 복습 800개에 막힌 사례](https://www.reddit.com/r/Anki/comments/1f0apnv/quit_anki_for_a_couple_of_months_now_i_have_800/)

**관찰:** 작성자는 약 1년 사용하다 몇 달 쉰 뒤 800개 복습이 남았고, 예전의 40~50개 수준으로 돌아갈 방법을 물었다. 댓글에는 나눠 처리하기, 새 카드 줄이기, 복습 제한 등 서로 다른 경험이 제시된다.

**해석의 한계:** 단일 자기보고이며 댓글의 처방을 검증된 해법으로 채택하지 않는다. 이 사례는 ‘처음 중단한 이유’보다 ‘복귀를 어렵게 한 상황’의 근거다.

**우리 가설:** 복귀 사용자는 전체를 초기화하거나 전부 끝내야 한다고 느끼지 않고, 적은 분량부터 재개할 수 있어야 한다. 실제 잔량은 확인 가능하게 유지한다.

## E04 · 계속 틀리는 카드를 그대로 반복함

**자료:** Anki 공식 매뉴얼. [Leeches](https://docs.ankiweb.net/manual/leeches)

**관찰:** 반복적으로 잊는 카드는 과도한 복습 시간을 차지할 수 있어 별도 식별한다. 설명 구성 변경, 이해 부족 확인, 참고용 보류, 비슷한 항목 사이 간섭 등을 다룬다.

**해석의 한계:** 특정 오답 횟수나 보류 정책이 우리 사용자에게 최적이라는 근거는 아니다.

**우리 가설:** 반복 오답은 학습자의 노력 부족으로만 처리하지 않는다. 한 카드에 뜻이 너무 많거나 문맥이 불분명한지 확인하고, 예문 변경·뜻 분리·보류를 제공한다.

## E05 · 점수와 출석이 공부의 목적을 대신함

**자료:** Hadi Mogavi 외 (2022), ACM Learning @ Scale. 9년간 포럼 자료 분석과 국제 사용자 15명 면담. [연구 원문](https://arxiv.org/html/2203.16175v1)

**관찰:** 게임화 보상에 몰입해 학습을 회피하거나 흥미·자신감을 잃었다는 사례를 분석했다. 경쟁과 보상에 대한 집착, 압박, 다른 사용자를 따라가는 행동 등이 보고됐다.

**해석의 한계:** 게임화 오용을 탐색한 표본이다. 모든 사용자에게 게임화가 해롭다는 결론이나 일반적인 발생률을 제공하지 않는다.

**우리 가설:** 연속 출석·문제 수만 성취로 표시하면 실제 기억과 사용 목적을 놓칠 수 있다. 목표와 직접 연결되는 지연 기억 확인을 별도로 측정한다.

## E06 · 너무 높은 성공 기준은 매일 공부해도 실패감을 만들 수 있음

**자료:** Duolingo 공식 제품 실험 보고. [Improving the streak](https://blog.duolingo.com/improving-the-streak/)

**관찰:** 과거 일일 목표를 모두 달성해야 출석 기록을 이어주던 방식에서, 한 수업을 완료하면 기록을 이어주는 방식으로 변경한 A/B 실험을 보고했다. 업체 보고상 14일 재방문은 상대적으로 3.3% 증가했지만, 일일 목표를 달성하는 사용자는 줄었다.

**해석의 한계:** 업체 자체 보고이며 3.3%포인트가 아니다. 재방문 개선이 어휘 기억 향상을 뜻하지 않는다. 과거 실험이며 현재 제품 전체의 동작을 설명하는 자료로 사용하지 않는다.

**우리 가설:** 짧게 공부한 것도 인정하되 작은 묶음 완료·전체 복습 완료·기억 확인을 별도로 표시한다. 출석 기능을 전부 배제할 이유도, 출석 증가만으로 효과를 주장할 이유도 없다.

## E07 · 자주 끼어드는 복습은 사용량과 방해를 동시에 늘림

**자료:** Schneegass 외 (2021), MuC. 30명이 3주 동안 잠금 해제 후 과제, 알림 과제, 일반 앱을 번갈아 사용한 현장 연구. [연구 원문](https://arxiv.org/html/2109.07944v1)

**관찰:** 일상 스마트폰 행동에 과제를 붙이면 응답 수는 증가했지만 개인별 선호가 달랐다. 급히 다른 일을 하려는 때 잠금 해제 과제가 방해되거나 집중 없이 답한다는 의견이 있었다. 연구의 중심 결과는 사용량과 경험이며 장기 기억 향상 검증과는 구분해야 한다.

**해석의 한계:** 짧은 기간, 초급 어휘, 특정 실험 앱 조건이다. 이 연구의 상시 알림 동작을 그대로 제품 권고로 옮기지 않는다.

**우리 가설:** 앱 진입·영상 종료·잠금 해제를 복습 강제 시작으로 연결하지 않는다. 바로 시작할 수 있는 제안과 중단 선택권을 함께 둔다.

## E08 · 오래 썼어도 매번 팝업을 닫는 일이 피곤함

**자료:** Reddit r/duolingo 공개 후기. [1,603일 연속 사용 후 중단을 고민한 사례](https://www.reddit.com/r/duolingo/comments/1x1s5lu/1603day_streak_and_im_considering_quitting/)

**관찰:** 작성자는 애니메이션·팝업·추가 클릭, 원하지 않는 기능, 체감 학습 효과를 불만으로 제시했다. 같은 토론에는 학습 효과에 만족하거나 소셜 기능을 긍정적으로 쓰는 반응도 있었다.

**해석의 한계:** 장기 사용자 한 명의 경험이며 실제 이탈 여부도 확정되지 않았다. 해당 서비스가 누구에게나 비효과적이라는 증거가 아니다. 검색 결과와 페이지의 상대 시각 표기가 달라 게시일은 특정하지 않고 조사일만 기록한다.

**우리 가설:** 정답마다 뜨는 보상 화면과 닫기 버튼을 없애고, 완료 피드백은 짧게 묶는다. 앱에 오래 머무는 시간보다 학습 목적에 도달하는 시간을 본다.

## E09 · 제대로 말했는데 틀렸다고 느끼면 평가를 믿지 않음

**자료:** Yuen & Schlote (2024), 캐나다 대학 두 곳의 성인 학습자 151명 설문과 20명 후속 면담. [연구 원문](https://journals.sagepub.com/doi/10.1177/00472395241238693)

**관찰:** 앱의 편리함·구조화·동기 부여를 긍정적으로 평가하는 경험과 함께, 두 참여자가 음성 인식의 부정확한 판정으로 좌절했다고 보고했다.

**해석의 한계:** 음성 판정이 실제로 틀렸는지를 독립 음성 평가로 확인한 연구가 아니라 참여자의 경험 보고다. 언어 학습자를 대상으로 한 설문이므로 일반 STT 오류율로 계산할 수 없다.

**우리 가설:** 인식한 텍스트를 확인할 수 있게 하고 기술적 인식 실패와 학습 오답을 분리한다. 인식 결과를 발음 실력 점수로 바로 바꾸지 않는다.

## E10 · 음성 기능의 이용 가능성은 환경과 브라우저에 따라 다름

**자료:** MDN Web API 문서, 조사일 확인. [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)

**관찰:** 브라우저 지원이 제한적이며 일부 브라우저의 인식은 서버를 이용해 오프라인에서 동작하지 않는다.

**해석의 한계:** 기술 제약에 대한 문서로, 대중교통 이용자의 선호를 측정한 자료는 아니다. 버스에서 말하기·듣기가 어렵다는 조건은 이번 사용자의 명시 요구이기도 하다.

**우리 가설:** 무음 복습은 독립적으로 완결되어야 한다. 오디오 로딩·마이크 권한·인식 실패가 핵심 복습을 막지 않게 설계한다.

## E11 · 익숙해진 느낌과 며칠 뒤 실제로 떠올리는 능력의 차이

**자료:** Karpicke & Roediger (2008), Science, 외국어 어휘 학습 실험. [저자 연구실의 논문 PDF](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf)

**관찰:** 한 번 맞힌 어휘를 이후에도 반복 인출한 조건에서 지연 기억에 이점이 있었고, 학습자의 기억 예측은 실제 수행과 일치하지 않았다.

**해석의 한계:** 자기평가 카드 UI·터치 횟수·STT·이동 중 사용을 비교한 연구는 아니다. 읽기가 무의미하다거나 모든 문제를 어려운 주관식으로 바꿔야 한다는 결론도 아니다.

**우리 가설:** 답을 떠올리는 시도와 피드백은 유지한다. 자기평가 수치를 객관적 정답률로 부르지 않으며, 나중의 독립적인 확인을 둔다.

## E12 · 한 번에 많이 반복하는 것과 오래 기억하는 것은 별도

**자료:** Cepeda 외 (2008), Psychological Science, 1,350명 이상이 참여한 사실 학습·지연 검사 연구. [저자 제공 연구 요약](https://www.yorku.ca/ncepeda/publications/CVRWP2008.html)

**관찰:** 학습 사이의 간격과 최종 검사 시점이 상호작용했고, 간격을 늘리는 것이 항상 더 좋은 것은 아니었다.

**해석의 한계:** 이 연구에서 우리 앱에 최적인 ‘1일·3일·7일’ 고정표나 단어별 정확한 망각 시점을 도출할 수 없다.

**우리 가설:** 같은 세션 재시도와 날짜를 달리한 기억 확인을 구분한다. ‘방금 다시 맞힘’을 장기 숙달로 표시하지 않는다.

## 사용자가 안 하게 되는 이유의 작업 분류

다음 표현은 사용자 진술의 직접 인용이 아니라, 위 근거를 바탕으로 만든 조사용 분류다. 빈도순이 아니다.

| 분류 | 조사에서 확인할 말·행동 | 관련 근거 | 제품에서 먼저 확인할 것 |
|---|---|---|---|
| 시작 비용 | 준비만 하다가 나중으로 미룸 | 설계 가설, E08의 조작 부담 | 자료 추가부터 첫 학습까지의 단계 |
| 분량 부담 | 오늘도 다 못 할 것 같아 안 켬 | E02, E03, E06 | 한 묶음과 전체 잔량을 어떻게 해석하는가 |
| 결과 불신 | 앱에서는 아는데 실제로 못 씀 | E08, E11 | 자기평가와 이후 실제 답의 차이 |
| 반복 피로 | 같은 어려운 카드에 계속 막힘 | E04 | 카드 이해, 관련성, 오답 이후 행동 |
| 환경 불일치 | 지금 말하거나 들을 수 없음 | 사용자 요구, E07, E10 | 무음·한 손·중단 후 복귀 |
