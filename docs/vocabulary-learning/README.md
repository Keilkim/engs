## 이번 조사에서 바뀐 판단

1. **조작을 줄이는 것과 공부 부담을 줄이는 것은 별도로 확인한다.** 복습을 5개씩 보여줘도 유입되는 항목이 더 많으면 누적은 계속 커질 수 있다. [Anki 공식 안내](https://docs.ankiweb.net/manual/deck-options)
2. **쉬었다가 돌아오는 경험을 첫 사용만큼 중요하게 다룬다.** 앱 불만 외에 학습 자체의 중단·재개도 있기 때문이다. [Huang, 2024](https://www.castledown.com/journals/tltl/article/view/tltl.v6n2.1187)
3. **2번 터치는 후보로 유지한다.** 답을 먼저 확인하게 하는 이점과, 확인 후 자기평가를 과신할 위험을 함께 비교한다. 이 UI의 우열을 입증한 결과는 아직 없다.
4. **틀린 카드의 품질을 개선하는 경로가 필요하다.** 반복 오답을 재출제만으로 처리하는 데 한계가 있을 수 있다. [Anki Leeches](https://docs.ankiweb.net/manual/leeches)
5. **음성 사용량보다 오류에서 회복 가능한지가 먼저다.** 잘못 판정되었다고 느끼는 경험이 좌절로 이어진 사례가 있다. [Yuen & Schlote, 2024](https://journals.sagepub.com/doi/10.1177/00472395241238693)

## 우선 진행할 일

| 순서 | 결정할 질문 | 방법 |
|---|---|---|
| 1 | 실제로 시작·복귀를 막는 것은 무엇인가 | 중단자·현재 사용자·시작 실패자 면담 |
| 2 | 무음 기본 흐름을 설명 없이 쓸 수 있는가 | 현재 방식과 후보 방식의 사용성 비교 |
| 3 | 조작 변화가 실제 기억에 도움이 되는가 | 24시간·7일 뒤의 독립적인 답 확인 |
| 4 | 듣기·말하기가 누구에게 추가 가치를 주는가 | 목표별 음성 파일럿, 오류 회복 점검 |
| 5 | 무엇을 구현·확대할 것인가 | 기억·부담·복귀 결과를 함께 검토 |

공개 자료 조사, 계획·질문지, 페르소나와 가상 인터뷰, 첫 제품 구현을 완료했다. 사용자가 구현·배포를 요청해 무음 기본 흐름과 선택적 듣기·말하기를 먼저 반영했다. [구현 결정과 남은 검증](implementation.md), [릴리스 기록](../releases/2026-10-30-vocabulary-practice.md)을 함께 본다. 실제 사용자를 접촉하거나 면담하지 않았으며, 재방문·지연 기억 실험은 참여자 확보 후 실행한다.
