# 구현 결정: 오늘의 작은 복습

2026-10-30 · 실제 사용자 검증 전 첫 버전

**앱을 열면 내가 저장한 단어 5개를 조용히 떠올리고, 확인하고, 끝낼 수 있다. 헷갈린 단어만 다시 도전하고, 다음 복습일에 다시 만난다.** 이 짧고 끝이 보이는 흐름을 재방문의 출발점으로 구현했다.

## 사용 흐름

1. 홈에서 `5개 복습 시작`을 누르면 첫 카드로 바로 간다. 7일 이상 쉬었다면 기본 분량을 3개로 줄인다. 읽던 자료와 자료 추가도 홈에서 접근한다.
2. 기본은 무음이다. 카드를 보고 `기억나요 / 기억 안 나요`를 고른다. 기억 안 나면 정답을 바로 보여주고, 기억나면 정답 뜻과 다른 저장 카드의 비슷한 뜻 중 하나를 골라 확인한다. 정답과 뜻이 겹치는 보기와 같은 문장의 다른 표현은 보기로 쓰지 않는다. 비교할 다른 카드가 없으면 `맞혔어요 / 다시 볼래요` 자기평가로 돌아간다. 말하기 모드는 영어로 답한 뒤 자기평가한다. 제한 시간은 없다.
3. 저장한 문장은 V 체크한 표현을 하나씩 묻고, 문장 전체는 카드 하단에 작게 보여준다. 복습 일정은 문장 단위로 유지하며 마지막 표현까지 모두 맞혀야 맞힌 것으로 기록한다.
4. 한 묶음이 끝나면 완료를 분명하게 보여준다. `여기서 마치기`를 우선 배치하고, 헷갈린 항목 재시도·다음 묶음·직접 고른 연습을 선택할 수 있다. 전체 잔량은 별도로 표시한다.
5. 다른 앱으로 이동하면 일시정지한다. 새로고침·페이지 이탈 후에는 계정별로 보관한 미완료 묶음과 답 공개 위치를 복원한다.
6. 처음 저장한 단어가 없다면 샘플 3개를 한 번 눌러 체험한다. 샘플은 실제 단어장·복습 일정·통계에 쓰지 않는다.

## 상황에 맞게 고르기

| 상황 | 구현 |
|---|---|
| 버스·한 손 | 기본 무음, 큰 버튼, 자동 음성 없음 |
| 이어폰 사용 | 듣기 버튼을 누른 뒤 표현 재생, 다음 카드도 명시적으로 재생 |
| 집에서 표현 연습 | 뜻을 보고 영어로 말하기 또는 입력하기, 인식 텍스트 확인 후 자기평가 |
| 마이크 거부·STT 오류 | 오답 기록 없음, 무음이나 글자 입력으로 계속 |
| 긴 공백·많은 잔량 | 작은 복귀 묶음, 전체 예정 개수 표시, 새 표현 수·분량·자료 범위 조절 |
| 계속 헷갈리는 단어 | 저장한 문장 힌트, 원문 이동, 선택적 영상 장면, 잠시 빼기·복원 |
| 특정 시험 범위 | 목록 검색, 자료 범위 선택, 최대 20개 직접 선택 연습 |
| 저장 실패 | 현재 답 유지, 같은 버튼으로 재시도, 서버 성공 확인 전 진행하지 않음 |

듣기는 소리→뜻, 말하기는 뜻→저장한 영어 표현이다. STT 문자열 일치는 발음 점수나 의미 채점이 아니다. 다른 표현·인식 오류는 직접 확인하게 하며 자동 오답으로 확정하지 않는다. 브라우저 음성 기능 지원은 기기에 따라 다르고 실제 마이크·이어폰 파일럿은 남아 있다.

## 기록과 복습 규칙

- 기존 SM-2 방식과 기존 Supabase 스키마를 유지한다. 같은 날 중복 제출과 같은 세션 재시도로 복습 간격을 여러 차례 늘리지 않는다.
- 서버 갱신은 사용자 ID와 이전 복습 상태를 함께 확인한다. 계정 변경 시 진행 중 요청을 무효화한다. 통계는 서버에서 새 결과가 확인된 경우만 별도로 집계한다.
- 계정별 브라우저 체크포인트에는 카드 ID, 답 확인 위치, 힌트 사용, 자기평가와 시간만 보관한다. 원문·녹음은 보관하지 않는다. 자동 로그인 해제 시 세션 저장소를 사용하며 7일 지난 체크포인트는 재개하지 않는다.
- 네트워크 응답이 유실되었어도 서버의 마지막 복습 시간이 세션 시작 이후라면 복원 시 재처리하지 않는다.
- 결과 화면은 `맞혔다고 체크`라고 표현한다. 당일 자기평가와 재시도 성공을 장기 기억의 증명으로 표시하지 않는다.

## 검증과 다음 판단

자동 테스트는 순서·분량·중단 복원·계정 경계·중복 저장·통계 경합·인식 미확정 처리를 확인한다. 격리된 브라우저 데이터로 모바일과 데스크톱의 실제 UI를 확인했다. 상세 결과는 [릴리스 기록](../releases/2026-10-30-vocabulary-practice.md)에 있다.

[5명 페르소나와 가상 인터뷰](../../personas/README.md)는 설계 검토용이다. 실제 면담, 재방문율 비교, 24시간·7일의 힌트 없는 기억 검사는 아직 진행하지 않았다. 참여자 모집 이후 [면담 가이드](interview-guide.md)와 [실험 계획](plan.md)으로 확인한다. 이 구현만으로 사용자가 반드시 다시 오거나 암기력이 향상된다고 단정하지 않는다.

후속 후보인 오터치 평가 되돌리기, 카드 뜻 직접 수정, 완전 오프라인 동기화, 선택적 알림, 독립적인 지연 검사 기록은 이번 버전에 포함하지 않았다. 연구에서 제안된 모든 기능을 한꺼번에 추가하기보다 이번 흐름의 사용성과 기억을 확인한 뒤 확장한다.
