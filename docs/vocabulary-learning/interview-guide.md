# 실제 사용자 면담·관찰 가이드

작성일: 2026-10-30 · 실행 상태: 질문지 준비, 모집·면담 미실시

## 목적

‘어떤 기능을 좋아하는가’보다 **최근 언제, 어떤 상황에서 공부를 미루거나 그만뒀는지** 확인한다. 사용자가 설명하는 이유와 실제 화면에서 관찰되는 행동을 함께 기록한다. 좋아할 것 같다는 답을 학습 효과나 재방문의 증거로 사용하지 않는다.

배경은 [조사 노트](evidence.md), 시안 비교와 기억 검사의 세부 설계는 [계획서](plan.md)에 있다.

## 모집안

첫 탐색 목표는 10명이며, 통계적 대표 표본이나 모든 문제를 발견하는 최소 인원으로 주장하지 않는다.

| 그룹 | 목표 인원 | 조건 |
|---|---|---|
| 최근 중단자 | 4명 | 최근 3개월 안에 단어·언어 앱을 사용하다 멈춤. 그중 복습 누적 경험자 포함 |
| 간헐·지속 사용자 | 4명 | 주기적으로 쓰는 사람과 자주 쉬었다 돌아오는 사람 모두 포함 |
| 시작 실패자 | 2명 | 설치·가입·자료 추가는 했지만 학습을 시작하지 못했거나 첫날 이후 멈춤 |

여러 그룹에 걸쳐 대중교통·무음 이용자, 시험 대비, 실무 표현, 영상 듣기, 초급 재시작, 전문 자료 읽기 상황을 포함한다. 특정 나이·직업만으로 기존 페르소나에 배정하지 않는다. 배우고 싶은 언어, 수준, 최근 사용 기기와 브라우저도 확인한다.

성공적으로 계속 사용하는 사람을 포함해 ‘불만이 있어도 계속 쓰는 이유’와 기존 앱이 잘하는 점을 찾는다. 제품을 좋아하는 지인만 모집하거나 부정적 후기 작성자만 조사하지 않는다.

## 사전 질문

1. 최근 사용한 언어·단어 학습 도구는 무엇이며, 마지막으로 쓴 때는 언제인가?
2. 지금도 그 언어를 배우고 싶은가? 원래 목표에 기한이 있었는가?
3. 앱을 멈췄더라도 다른 방식으로 공부하고 있는가?
4. 주로 어디서 몇 분 정도 사용했으며, 소리·말하기·타이핑 중 무엇이 가능한가?
5. 가능하다면 본인이 공유해도 되는 단어·화면·자료 한 가지를 면담 때 보여줄 수 있는가? 없어도 참여할 수 있다.

## 30분 진행안

### 0~5분: 목표와 최근 상황

- “영어를 배우는 이유를 가장 최근에 실감한 일이 있었나요?”
- “가장 최근 공부하려던 순간을 시간·장소·하던 일 순서로 설명해 주세요.”
- “그때 앱을 켜서 무엇을 하려고 했나요? 실제로 어디까지 했나요?”

목표를 ‘말하기 실력 향상’처럼 추상적으로만 기록하지 않고, 회의 질문·여행 안내·논문 한 문단 등 실제 과제로 구체화한다.

### 5~13분: 마지막 실패 장면 재구성

- “공부하려다 나중으로 미룬 가장 최근 상황은 어땠나요?”
- “마지막으로 멈춘 화면이 기억나나요? 그다음에는 무엇을 했나요?”
- “시간이 없었다고 하셨는데, 2분도 없었나요, 끝낼 분량을 몰랐나요, 아니면 생각할 기운이 없었나요?”
- “같은 단어를 다시 찾았던 최근 일은 언제였나요?”
- “틀렸을 때 앱은 무엇을 보여줬고, 그 뒤에는 어떻게 했나요?”
- “다시 돌아오려고 했다면 무엇이 걸렸나요? 돌아온 적이 있다면 무엇 덕분이었나요?”

선택지를 먼저 읽어주지 않고 경험을 들은 뒤 필요한 경우에만 좁혀 묻는다. ‘의지가 부족해서’, ‘앱이 별로라서’라는 평가에 멈추지 않고 당시 행동과 조건을 확인한다.

### 13~23분: 설명 없이 시안 사용

현재 방식과 후보 방식의 제시 순서를 참가자별로 바꾼다. 각 과제의 의도는 아래와 같으며, 진행자는 버튼의 정답 위치나 제스처를 먼저 알려주지 않는다.

| 과제 | 참가자에게 주는 상황 | 관찰할 것 |
|---|---|---|
| 무음 시작 | “버스에 앉아 있고 이어폰은 없습니다. 다음 정류장 전까지 조금 공부해 보세요.” | 소리·마이크 없이 시작 가능한가, 한 손으로 조작하는가 |
| 의미 확인 | “떠오르는 답을 생각한 뒤 평소처럼 진행해 주세요.” | 답을 본 시점, 평가 기준, 문구 해석 |
| 중단 | “이제 내려야 해서 잠깐 나갔다가 다시 돌아왔다고 해볼게요.” | 멈추는 방법, 복원 예상, 이어하기 위치 |
| 복귀 | “며칠 쉬었다가 돌아왔고 예정 복습은 많이 남아 있습니다.” | 전체 의무로 느끼는지, 오늘 할 양 선택 |
| 본래 목적 | “지금은 단어보다 읽던 자료를 이어 읽으려고 들어왔습니다.” | 복습 제안이 읽기를 방해하는지 |
| 음성 실패 | 음성 목표 참가자에게만 인식이 잘못된 예시 제시 | 학습 오답으로 받아들이는지, 수정·전환을 찾는지 |

말하면서 생각하는 관찰 과제는 실제 버스 무음 학습 조건과 다르다. 조작 시간을 비교하는 구간에서는 설명을 멈추게 하고, 해당 구간 뒤에 이유를 묻는다. 실험자가 유도한 인식 오류는 실제 자연 발생 오류와 구별해 기록한다.

### 23~30분: 반례와 선택 이유

- “내일 실제로 사용한다면 어느 흐름을 고르겠어요? 고르지 않은 쪽은 언제 더 편할까요?”
- “이 방식이 너무 느리거나 쉬울 때가 있을까요?”
- “오늘은 이 정도로 마쳐도 된다고 느낀 지점은 어디였나요?”
- “여기서 ‘맞혔어요’를 눌렀다는 것은 본인에게 어떤 의미인가요?”
- “앱을 그만 쓰더라도 목표는 달성했다고 볼 수 있는 상황은 무엇인가요?”
- “새 기능 없이 기존 도구로도 해결할 수 있는 부분이 있나요?”

좋았다는 평가 뒤에는 어떤 순간 때문인지 묻고, 불편했다는 평가 뒤에는 실제로 학습을 중단할 정도인지 확인한다.

## 목표별 추가 질문

| 상황 | 추가 질문 |
|---|---|
| 시험 대비 | 시험 직전에는 적은 묶음과 전체 범위 중 무엇을 원하는가? 비슷한 뜻을 헷갈린 실제 문제는 무엇인가? |
| 직장·표현 생성 | 뜻은 알지만 말하지 못한 최근 문장은? 출근길에 할 수 있는 입력은 어디까지인가? |
| 영상 듣기 | 자막을 열었던 정확한 순간은? 익숙한 장면을 기억한 것과 소리를 알아들은 것을 어떻게 구별하는가? |
| 초급 재시작 | 모르는 문제를 만나면 어떤 도움부터 찾는가? 적은 분량이 안심되는가, 의미 없게 느껴지는가? |
| 논문·전문 자료 | 문맥에서만 필요한 뜻을 어떻게 남기는가? 저장했지만 외울 필요 없는 단어가 있는가? |

## 피할 질문과 대체 질문

| 피할 질문 | 대체 질문 |
|---|---|
| “5개만 하면 부담 없겠죠?” | “지금 끝내고 싶은 분량은 어디까지인가요?” |
| “STT가 있으면 편하겠죠?” | “그 장소에서 말할 수 있었나요? 답을 어떻게 남겼나요?” |
| “스트릭 때문에 스트레스받았나요?” | “연속 기록을 보고 어떤 행동을 했나요?” |
| “잘 외워졌나요?” | “지금 답을 가리고 설명해 볼 수 있나요?” |
| “왜 꾸준히 못 했나요?” | “마지막으로 공부하려던 순간에 어떤 일이 있었나요?” |

## 기록 양식

```text
참가자 ID / 그룹 / 면담일:
현재 목표와 목표가 필요한 실제 상황:
최근 기기·장소·가용 시간·오디오/발화 조건:
마지막 사용 또는 중단 장면:
하려던 행동 → 실제 행동 → 그다음 행동:
참가자가 말한 이유:
관찰한 조작·멈춤·오류:
진행자가 제공한 도움:
시안 제시 순서와 자료:
기존 도구가 잘한 점:
제품 불만 / 환경 제약 / 목표 변화 / 기타 / 아직 불명:
설계자의 해석과 이를 반박할 수 있는 설명:
바꾸고 싶은 가설 / 추가 확인할 질문:
```

직접 진술·관찰·해석을 서로 다른 칸에 적는다. 조사에서 만난 3명이 같은 말을 했다고 ‘사용자의 30%가 원한다’는 모집단 수치로 보고하지 않는다. 실제로 등장하지 않은 항목은 빈칸으로 둔다.

## 면담 뒤의 다음 행동

1. 실패 장면을 시작·진행·중단·복귀·목표 변화로 분류한다.
2. 기존 [근거 E01~E12](evidence.md)와 일치한 점뿐 아니라 반례를 기록한다.
3. 해결할 필요가 없는 정상적인 종료와 제품이 막은 학습을 구분한다.
4. [계획서](plan.md)의 우선순위·시안·용어를 수정한다.
5. 지연 기억 검사는 별도 일정을 동의받아 진행한다. 면담 중 선호만으로 암기 효과를 결론 내리지 않는다.
