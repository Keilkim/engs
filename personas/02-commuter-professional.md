# P02 · 박준호 — 출퇴근 틈에 배운 표현을 업무에서 꺼내 쓰려는 직장인

> 2026-10-30 작성. 제품 설계를 위한 가상 페르소나이며 실제 사용자 조사 결과가 아니다. 이름, 나이, 학습량과 아래 인터뷰 답변은 모두 가정이다.

## 기본 상황

| 항목 | 설정 |
|---|---|
| 나이·생활 | 32세, 해외 고객과 주 2회 회의하는 B2B 서비스 기획자 |
| 학습 계기 | 읽으면 아는 표현이 회의에서는 떠오르지 않아 같은 쉬운 말만 반복함 |
| 영어 상태 | 일반 업무 문서를 읽을 수 있지만 즉석에서 문장을 만드는 데 시간이 걸림 |
| 자료 | 공개 제품 소개 글, 업무 관련 인터뷰 영상, 직접 입력한 표현 |
| 기기·환경 | 지하철에서 휴대폰을 한 손으로 사용. 말하기 어렵고 이어폰도 매번 쓰지는 않음 |
| 사용 시간 | 출근 중 4분, 점심 뒤 3분. 회의가 생기면 언제든 중단 |
| 가상의 이용 상태 | 가입 2개월 차. 저장 표현 96개, 오늘 복습 대상 18개 |
| 지금 쓰는 대안 | 휴대폰 메모에 표현을 모으지만 급할 때만 검색함 |

## 이루려는 일

“짧게 시간이 났을 때 다음 업무에서 쓸 표현 몇 개를 떠올려 보고, 회의에서 말이 막히는 횟수를 줄이고 싶다.”

목표는 단어 뜻을 읽고 이해하는 데서 끝나지 않는다. **말하려는 상황에서 영어 표현을 꺼내는 것**이 필요하다.

## 실제로 일어날 법한 하루와 실패 장면

1. 출근길에 인터뷰에서 `clarify`를 저장한다.
2. 복습 카드에서 단어를 보면 ‘명확히 하다’라는 뜻을 알고 있어 ‘알아요’를 누른다.
3. 오후 회의에서 요구사항을 확인하려는데 `Could you clarify ...?`가 떠오르지 않는다.
4. 밤에 문장을 써 보겠다고 생각하지만 야근하면 넘어간다.
5. 다음 날 복습을 시작해도 내려야 할 역에 도착하면 세션을 중단한다.

짧은 학습을 원하지만 쉬운 문제만 반복하는 것은 시간 낭비라고 느낀다. 출퇴근과 집에서 가능한 입력 방식도 다르다.

## 첫 화면에서 기대하는 것

- 가장 큰 행동: **`오늘 쓸 표현 5개 떠올리기`**.
- 안내: 이번 묶음의 개수와 대략적인 소요 시간. 시간은 실제 사용 기록으로 조정한다.
- 보조 행동: `하던 복습 이어서`, 읽던 자료 이어 보기.
- 문제 예시: “‘납기를 다시 확인해 주시겠어요?’를 영어로 어떻게 말할까?”
- 피하고 싶은 화면: 시작 전에 학습 모드·난이도·문제 수를 매번 정해야 하는 화면.

## 가상 인터뷰

**Q1. 최근 단어를 외우려다 실패한 순간은?**

“`clarify`를 보면 알아요. 그런데 제가 질문해야 할 때는 그 단어가 안 나와요. 뜻을 아는 거랑 쓰는 게 다른 것 같아요.”

**Q2. 앱을 열고 첫 10초에 무엇을 확인하고 싶은가?**

“지금 3~4분 안에 끝낼 게 뭔지만 알려주세요. 어제 하다 만 게 있으면 거기서 이어가고요.”

**Q3. 들어오자마자 ‘바로 시험보기’가 있으면 누를 것인가?**

“몇 개만 하는 거면 눌러요. ‘시험’이라고 크게 쓰여 있으면 길게 해야 할 것 같아요. 저는 ‘표현 5개 연습’이 더 정확하게 느껴져요.”

**Q4. 답이 생각나지 않을 때 무엇이 필요한가?**

“첫 단어나 짧은 힌트가 있으면 한 번 더 생각할게요. 그래도 모르겠으면 제가 실제로 쓸 만한 예문 하나를 보여주세요.”

**Q5. 일주일 쉬어서 복습할 단어가 많이 쌓이면?**

“이번 주 업무에 가까운 것부터 조금씩 할래요. 지난주 걸 다 끝내야 새 연습을 할 수 있으면 그냥 닫을 것 같아요.”

**Q6. 어떤 결과를 보면 실제로 외웠다고 느끼는가?**

“한국어 상황만 보고 영어 표현을 만들 수 있을 때요. 앱 밖 회의에서 써봤으면 더 확실하고요.”

**Q7. 처음 가입해서 저장한 단어가 없다면?**

“자료 올리는 데 오래 걸리면 나중에 할 것 같아요. 샘플 표현 3개로 먼저 해보고 제 관심 글을 넣고 싶어요.”

## 설계에 주는 요구와 반례

- 한 번에 끝낼 수 있는 묶음을 제공하고, 중단해도 처리한 항목과 남은 위치를 보존한다.
- 영단어→뜻뿐 아니라 상황→영어 표현 방향을 선택할 수 있어야 한다.
- 출근길에는 조용히 생각한 뒤 확인할 수 있게 하고, 타이핑·음성 입력을 강제하지 않는다.
- 자기평가만 한 답은 자동 채점된 정답처럼 표현하지 않는다.
- 반례: 회의가 없는 주에는 업무 표현보다 읽고 있던 관심 글로 바로 가고 싶을 수 있다.

## 실제 사용자에게 확인할 가설

1. 작은 묶음과 중단 후 이어하기 중 어느 쪽이 복습을 다시 시작하는 데 더 중요한가?
2. 상황을 보고 표현을 떠올리는 문제가 대중교통에서도 부담 없이 가능한가?
3. 단어를 맞혔다는 결과보다 직접 만든 짧은 문장을 남기는 것을 더 가치 있게 여기는가?

실제 면담에서는 **가장 최근 영어 회의에서 말하지 못한 문장과, 그 뒤 실제로 한 행동**을 묻는다.
