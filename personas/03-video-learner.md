# P03 · 이하린 — 좋아하는 영상의 말을 자막 없이 알아듣고 싶은 학습자

> 2026-10-30 작성. 제품 설계를 위한 가상 페르소나이며 실제 사용자 조사 결과가 아니다. 이름, 나이, 학습량과 아래 인터뷰 답변은 모두 가정이다.

## 이루려는 일

“재미있게 보던 영상에서 놓친 표현을 다시 만났을 때, 자막을 켜지 않고도 알아듣고 싶다.”

관심 콘텐츠를 이해하는 것이 목적이다. **단어 암기가 영상 감상과 연결되어 있으면** 시간을 쓰지만, 별도 시험 과목처럼 느껴지면 멀어진다.

## 실제로 일어날 법한 하루와 실패 장면

1. 인터뷰에서 `figure out`을 저장하고 장면을 두 번 다시 듣는다.
2. 며칠 뒤 글자로 된 카드에서는 뜻을 쉽게 말한다.
3. 다른 영상에서 빠르게 이어진 같은 표현은 알아듣지 못한다.
4. 원래 장면을 찾으려다 영상 전체를 다시 훑고, 다른 추천 영상을 보기 시작한다.
5. 단어장에 저장한 표현은 늘지만 다시 듣는 습관은 생기지 않는다.

좋아하는 영상은 동기가 되지만 동시에 복습을 벗어나는 통로가 된다. 원래 영상으로 이동할 선택권과 짧은 복습의 끝이 모두 필요하다.

## 첫 화면에서 기대하는 것

- 가장 큰 행동: **`어제 저장한 장면 3개 다시 듣기`**.
- 콘텐츠 단서: 영상 제목과 작은 썸네일. 어떤 기억을 확인하는지 알 수 있다.
- 보조 행동: `영상 이어 보기`, `소리 없이 복습`.
- 듣기 연습에 들어가면: 사용자가 재생을 누르고, 먼저 소리를 들은 뒤 필요할 때 자막을 연다.
- 피하고 싶은 화면: 로그인과 동시에 소리가 나오거나, 영상에서 저장한 표현이 출처 없이 나열되는 화면.

## 가상 인터뷰

**Q1. 최근 단어를 외우려다 실패한 순간은?**

“`figure out`을 글자로 보면 아는데 소리로는 놓쳤어요. 단어장에서는 아는 걸로 나와서 뭘 더 해야 하는지 모르겠어요.”

**Q2. 앱을 열고 첫 10초에 무엇을 확인하고 싶은가?**

“제가 보던 영상이랑 저장한 장면이요. ‘이 부분 이번에는 들리나?’ 하면 해볼 것 같아요.”

**Q3. 들어오자마자 ‘바로 시험보기’가 있으면 누를 것인가?**

“그냥 시험이면 안 누를 수도 있어요. 제가 저장한 장면 몇 개를 들어보는 거면 할래요. 그래도 바로 영상을 볼 수는 있어야 해요.”

**Q4. 답이 생각나지 않을 때 무엇이 필요한가?**

“한 번 더 듣고, 그다음 자막을 켜고 싶어요. 처음부터 단어와 번역이 다 있으면 제가 들은 건지 읽은 건지 모르겠어요.”

**Q5. 일주일 쉬어서 복습할 단어가 많이 쌓이면?**

“지금도 관심 있는 영상에서 몇 개만 보고 싶어요. 이미 흥미가 없어진 영상의 표현은 빼거나 나중으로 미루고요.”

**Q6. 어떤 결과를 보면 실제로 외웠다고 느끼는가?**

“전에 안 들렸던 장면이 들리면 기분이 좋아요. 다른 사람이 같은 표현을 말했을 때도 알아들으면 더 확실하겠죠.”

**Q7. 처음 가입해서 저장한 단어가 없다면?**

“제가 좋아하는 영상 링크를 넣고 한 표현을 저장해 보는 게 좋아요. 그 장면이 어떻게 복습으로 나오는지도 바로 보고 싶고요.”

## 설계에 주는 요구와 반례

- 기존 원본 장면 재생 기능을 듣기 연습의 출발점으로 검토한다.
- ‘자막 없이 들음’, ‘자막을 보고 확인함’, ‘텍스트 뜻을 앎’을 구분한다.
- 재생과 자막 공개는 사용자가 선택한다. 이어폰을 연결했다고 자동 재생하지 않는다.
- 장면 정보가 없는 카드와 재생이 안 되는 영상에는 텍스트 복습 경로를 제공한다.
- 반례: 재미있는 영상이어도 이미 여러 번 들은 장면만 반복하면 문장 자체를 외워 듣기 실력을 과대평가할 수 있다.

## 실제 사용자에게 확인할 가설

1. 저장 장면을 보여주면 일반 단어 카드보다 복습을 더 자주 시작하는가?
2. 원본 영상으로 이동하는 행동이 학습의 연장인지 복습을 피하는 행동인지 어떻게 구분할 것인가?
3. 익숙한 장면을 이해한 뒤, 다른 화자의 새 문장에서도 같은 표현을 알아듣는가?

실제 면담에서는 **최근 자막을 켜거나 되감았던 장면을 함께 보고, 어느 부분에서 막혔는지** 묻는다.
