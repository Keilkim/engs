# 단어 학습 사용자 페르소나 5명과 가상 인터뷰

작성일: 2026-10-30

## 이 문서의 성격

오렌지 더스트에서 **단어를 더 잘 기억하게 하려면 무엇이 필요하고, 앱을 열었을 때 무엇을 먼저 보여줘야 하는지** 검토하기 위한 초안이다. ‘들어가면’은 우선 앱 홈에 재방문하는 상황으로 해석했고, 각 인물의 첫 가입 상황도 함께 다뤘다.

5명 모두 가상 인물이다. 나이, 생활, 수준, 이용 기간, 학습량, 인용문은 설계를 위한 가정이며 실사용 로그나 실제 면담에서 나온 정보가 아니다. 인터뷰는 각 인물의 조건에 따라 작성한 역할 시뮬레이션이다. 의견이 비슷하게 나와도 사용자 다수의 선호나 학습 효과가 검증된 것은 아니다.

페르소나는 나이에 따라 기능을 나누기 위한 분류가 아니다. 목표, 사용 환경, 기억해야 하는 방식과 학습을 중단하는 이유의 차이를 검토하는 데 쓴다. 한 사용자도 시험 전날, 출근길, 주말에 서로 다른 상황에 놓일 수 있다.

## 가상 인터뷰에서 도출한 설계 가설

### 1. 재방문 홈에는 작은 복습 묶음을 시작하는 행동을 눈에 띄게 둔다

첫 시안으로는 다음 구성을 검토한다. 개수와 시간은 예시이며 최적값으로 검증된 수치가 아니다.

```text
오늘은 저장한 단어 5개부터
지난번 헷갈렸던 단어를 다시 떠올려 보세요.

[ 5개 복습 시작 ]

읽던 자료 이어 보기      내 단어장
시험 범위 정해서 풀기
```

‘지난번 헷갈렸던’이라는 문구는 해당 기록이 있을 때만 쓴다. 시간이 표시된다면 실제 이용 기록에 근거한 예상치여야 한다. 첫 시안부터 문항 수·분량·예상 시간에 대한 약속을 혼동하지 않게 한다.

버튼을 누르면 첫 문제로 바로 간다. 앱에 들어온 것만으로 문제를 자동 시작하지 않는다. 자료를 읽는 목적도 있으므로 이어 읽기와 자료 추가에 쉽게 접근할 수 있게 한다. 묶음 완료를 ‘오늘의 전체 복습 완료’로 표시해서는 안 된다.

### 2. ‘바로 시험보기’는 목적이 분명한 선택지로 둔다

- 시험 대비에서는 범위와 문항 수를 보여주는 ‘시험보기’가 적합하다는 가설이 있다.
- 일상 복습에서는 ‘단어 5개 떠올리기’처럼 실제 할 일을 설명하는 이름을 검토한다.
- 영상 학습에서는 기존 장면 재생을 활용한 듣기 시작점을 검토한다.
- 읽기가 우선인 사용자는 자료로 바로 갈 수 있어야 한다.

5종류의 홈을 한꺼번에 만들거나 나이·직업으로 모드를 자동 배정하자는 뜻은 아니다. 공통 첫 화면을 먼저 검토하고, 사용자가 선택한 목적과 이용 가능한 자료에 따라 연습 방식을 바꾸는 후속 가설로 남긴다.

### 3. 답을 본 뒤의 다음 행동까지 설계한다

검토할 흐름은 **답을 가리고 떠올리기 → 필요하면 힌트·원문 보기 → 뜻 확인 → 몇 문제 뒤 다시 시도 → 다음 복습일에 다시 확인**이다. 같은 세션 재시도는 현재 구현에 없는 제안이다. 바로 다시 맞힌 것과 며칠 뒤 기억한 것을 구분해 기록할 필요가 있다.

‘알아요’ 자기평가만으로 실제 기억이나 사용 능력을 확정하지 않는다. 뜻 이해, 영어 표현 떠올리기, 소리로 알아듣기 중 무엇을 확인했는지 분명하게 한다. 입력·객관식·음성 중 특정 방식을 모든 사람에게 강제하지 않고, 실제로 필요한 방식부터 검증한다.

## 첫 방문·복귀·복습 종료 때의 차이

| 상태 | 첫 행동 후보 | 유의할 점 |
|---|---|---|
| 저장 단어 없음 | 샘플 3개 체험 또는 내 자료 추가 | 샘플 체험을 의무로 만들지 않으며, 이미 학습한 단어처럼 기록하지 않는다 |
| 오늘 복습 대상 있음 | 작은 묶음 바로 시작 | 전체 대상 수와 이번 묶음 수를 구분하고 전체 목록도 볼 수 있게 한다 |
| 오래 쉬었다가 복귀 | 소량으로 다시 시작 | 남은 항목을 삭제하거나 다 끝낸 것처럼 표시하지 않는다 |
| 작은 묶음 완료, 남은 대상 있음 | 여기서 마치기 또는 다음 묶음 | 중단을 실패로 표시하지 않는다 |
| 오늘 대상 모두 완료 | 읽던 자료 이어 보기 | 없던 복습 과제를 만들어 완료 상태를 흐리지 않는다 |

## 먼저 검증할 순서

1. **홈에서 복습 시작:** 현재 홈과 ‘작은 묶음 시작’ 시안을 비교한다. 메뉴 설명 없이 첫 행동을 고르게 하고, 무엇을 하게 될 것으로 예상하는지 묻는다.
2. **짧은 복습의 내용:** 기존 자기평가와 뜻·상황·듣기 과제를 실제 목표에 맞춰 사용해 본다. 시작·완료뿐 아니라 도움을 열었던 순간과 중단 이유를 확인한다.
3. **기억 확인:** 당일 반복 정답과 며칠 뒤 힌트 없는 답을 분리해 본다. 읽기·표현·듣기를 하나의 점수로 합치지 않는다.

실제 모집에서는 각 행동 유형에 가까운 사람을 찾아 관찰한다. 가상 인물 5명은 실제 참여자 5명을 뜻하지 않으며, 이 문서로 효과 크기나 필요한 조사 인원수를 정할 수 없다. 클릭이 늘었다는 결과만으로 단어를 더 잘 외우게 되었다고 결론 내리지 않는다.

우선 검토할 제안은 **‘저장한 단어 몇 개를 바로 떠올려 보는 홈’**이다. 시험 모드, 장면 듣기, 자료별 복습은 각 목표에 맞는 선택지로 검토한다. 이 단계에서는 페르소나와 설계 가설만 작성했으며 앱 동작은 변경하지 않았다.

## 후속 조사와 계획

최소 터치·직관성·암기 효과·무음 환경을 함께 고려한 [조사와 검증 계획](../docs/vocabulary-learning/README.md)을 추가했다. 실제 후기·연구·공식 자료 12건을 검토했으며, 이 문서의 가상 답변과 구분한다. ‘5개 묶음’과 ‘2번 터치’는 후속 계획에서도 비교할 가설로 남겨두었다.
