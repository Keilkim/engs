# P04 · 최민정 — 여러 번 중단한 뒤 영어를 다시 시작한 초급자

> 2026-10-30 작성. 제품 설계를 위한 가상 페르소나이며 실제 사용자 조사 결과가 아니다. 이름, 나이, 학습량과 아래 인터뷰 답변은 모두 가정이다.

## 이루려는 일

“오랜만에 다시 공부하러 왔을 때 어디서 시작할지 바로 알고, 조금이라도 해냈다는 경험을 쌓고 싶다.”

단어를 틀리는 것 자체보다 **틀렸을 때 무엇을 해야 할지 모르는 상황**이 어렵다. 부드러운 표현만 있고 방법이 없는 화면도 도움이 되지 않는다.

## 실제로 일어날 법한 하루와 실패 장면

1. 여행 준비 중 `reservation`을 저장하고 뜻과 발음을 확인한다.
2. 며칠 뒤에는 단어를 봐도 읽는 법이 기억나지 않아 바로 답을 연다.
3. 카드 뒷면을 읽고 다음으로 넘어가지만, 잠시 뒤에는 다시 생각나지 않는다.
4. 바쁜 기간이 지나 돌아오니 복습 대상이 한 화면에 많이 표시된다.
5. 전부 해야 할 숙제처럼 느껴져 시작을 미루고, 공부하지 않은 날이 더 길어진다.

쉬운 성공을 원하지만 의미 없는 축하에는 관심이 없다. 전에 모르던 표현 하나를 직접 이해했다는 경험을 원한다.

## 첫 화면에서 기대하는 것

- 가장 큰 행동: **`익숙한 단어 3개부터 시작하기`**.
- 안내: ‘오늘은 이 묶음만 해도 괜찮아요. 더 하고 싶으면 이어갈 수 있어요.’
- 처음 저장하는 단어는 뜻·발음을 알아보는 단계와 기억을 확인하는 단계를 구분한다.
- 보조 행동: 읽던 여행 자료 이어 보기, 전체 복습 목록.
- 피하고 싶은 화면: 남은 단어 수만 크게 보이거나 영어로만 된 학습 안내.

## 가상 인터뷰

**Q1. 최근 단어를 외우려다 실패한 순간은?**

“그때는 이해했는데 며칠 지나면 읽는 법부터 모르겠어요. 답을 보고 넘기는 것 말고 뭘 해야 할지 모르겠어요.”

**Q2. 앱을 열고 첫 10초에 무엇을 확인하고 싶은가?**

“오늘 누를 버튼 하나가 분명했으면 해요. 3개부터라고 하면 해볼 수 있을 것 같아요.”

**Q3. 들어오자마자 ‘바로 시험보기’가 있으면 누를 것인가?**

“처음 보는 단어를 시험 보면 겁날 것 같아요. 배운 것 몇 개를 확인하는 거면 괜찮아요. 모르면 어떻게 다시 배우는지도 보여주세요.”

**Q4. 답이 생각나지 않을 때 무엇이 필요한가?**

“뜻 하나, 발음 한 번, 짧은 예문 하나면 좋겠어요. 설명이 길면 더 헷갈려요. 보고 나서 다시 떠올려볼 기회도 있으면 좋겠고요.”

**Q5. 일주일 쉬어서 복습할 단어가 많이 쌓이면?**

“전부 해야 한다고 느끼면 미뤄요. 전체 목록은 남겨두고 오늘은 조금부터 다시 시작하게 해주세요.”

**Q6. 어떤 결과를 보면 실제로 외웠다고 느끼는가?**

“어제 답을 봤던 단어를 오늘은 제가 알아봤을 때요. ‘점수 60점’보다 어떤 단어를 다시 알아봤는지가 궁금해요.”

**Q7. 처음 가입해서 저장한 단어가 없다면?**

“파일부터 넣으라고 하면 어려울 수 있어요. 여행 표현 3개로 버튼 쓰는 법을 배운 뒤 제 자료를 넣고 싶어요.”

## 설계에 주는 요구와 반례

- 신규 단어를 알아보는 경험과 이미 본 단어의 기억 확인을 구분한다.
- 도움말·발음·뜻을 쉽게 찾게 하되, 한 번에 많은 설명을 펼치지 않는다.
- 오답 확인 뒤 짧은 묶음 안에서 다시 시도하는 흐름을 검토한다.
- 복귀 시 작은 묶음을 제안하고, 전체 목록은 사용자가 열어볼 수 있게 둔다.
- 반례: ‘쉽게’, ‘초보용’을 과하게 강조하거나 어린이처럼 대하는 문구는 성인 사용자의 의욕을 떨어뜨릴 수 있다.

## 실제 사용자에게 확인할 가설

1. ‘시험’이라는 단어가 문제인지, 실제 난이도·문항 수·오답 경험이 문제인지 구분해야 한다.
2. 작은 묶음이 복귀를 돕는가, 아니면 너무 사소해서 학습 가치가 낮다고 느끼는가?
3. 초급자에게도 계속 보기만 하는 카드보다 도움을 받으며 답을 떠올리는 방식이 수용 가능한가?

실제 면담에서는 **이전에 그만둔 학습 앱의 마지막 사용 상황과, 다시 시작할 때 가장 먼저 필요했던 것**을 묻는다.
